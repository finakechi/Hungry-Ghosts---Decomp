`hg_resource_worker_fixed(env, frame)` composes existing request/worker/PACK/M1

forwards other calls. Existing `hg_resource_worker` retains the isolated M2 seam;
old model receipts still label fixups as mocks. No new memory framework or runner
was introduced. The runner adds only DSLL32/DSRL32 and executed-address accounting.

1389d0 is a signed address permutation using a table at 3e0260. It does not
allocate, publish or notify; rebase discards its return. This resolves M3's unknown
helper role. Its signed negative-index lookup uses guest scratch before its table.

The scratch argument is an explicit host adapter for the original adjusted sp.
For composition, reserve aligned, separate `[frame-0x70, frame+0x240)` guest memory;
valid larger lists may require more guest space, just as original stack overflow
writes may go beyond that frame. Tests exercise 16/17 texture and 64/65 model
entries, including adjacent-array spill. ABI save/restore instructions run in the
instruction model; C does not populate those original register-save slots. No
claim covers arbitrary malformed indices reading those omitted saves, arbitrary
64-bit argument lanes, concurrent memory changes or bus side effects. The model
checks canonical sign-extended word arguments and all original callee-saved lanes.
Unaligned/unmapped access and unterminated chains remain bus/budget boundaries;
C does not silently invent rejection or termination semantics.

Geometry/material processing **1386e0** and upload **152ae0** remain explicit,
argument-tested external operations. Their bodies are not counted as reconstructed;
the selected resource calls neither. Type-1 resources therefore still require that
separate subsystem. Alternate ID control flow is instruction-tested, not retail
runtime-tested.
