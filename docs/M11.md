## C reconstruction boundary (Gate 2)

`0015fe70` (M9) ends by computing the movement direction from history `+390` to
the proposed `+30`, then calls `0015ebc0(direction, player)` and `0015fc10(player)`.
`0015fc10` is gravity plus the floor query `0015e420` and stays modeled.
`0015eaf0` is reached only through special-surface hits, which were never
observed. The smallest connected boundary that makes the response decisions is the
whole of `0015ebc0`, implemented as `hg_player_static_constraint`:

- **Probes.** Head (+16.5 y) and middle (+8.25 y) segments run 4 units out at
  −90, −45, 0, +45 and +90 degrees around the movement direction. Foot (+3 y)
  segments run from 2 units behind to 4 ahead. Then 1 rear probe, or 3 when
  `+4ad` is set. Angles use `mul.s`, `div.s` (round to nearest under PCSX2
  defaults) and `add.s`, then the M9 C wrap.
- **Hit filter.** A zero result is ignored. Bit `0x100` counts only when the hit
  record's `3f39c4` has bit 2. `0x1e00` special surfaces fail closed (domain
  code 0x40).
- **Facing test (VU0 macro).** `c00 = (b90 − b80).xyz` (w keeps `b90.w`). Then
  `Q = vrsqrt(1, |c00|²)` with the root and the division each chopped,
  `c00 = c00·Q`, `dot = c00 · normal(3f3a10)`, and `c.le.s dot, threshold`.
  The threshold is −0.3, or −0.7 for foot and rear probes when `+4ad` is set.
- **Response.** X and Z (not Y) add the push `3f39b0/3f39b8`, then that tier's
  probes restart from the corrected position. Head pushes *assign*
  `side | 1`; middle, foot and rear pushes OR in `0x30` / `0x100`.
- **Bump.** The test uses `|wrap(+44 − direction)| ≥ 2.967` (backing into a wall)
  with flags avoiding `0x22`, or flags exactly `0x100`. If `+508` is 0 and `+49a`
  bit 8 is clear, it arms `+508 = 0x50`. When `+49c` is set it then draws a random
  number, selects one of four sound IDs from `3e0850`, and requests it with
  volume `127 × 3eaa78` (finite [0,1] only, otherwise domain 0x41). Finally the
  timer decrements, `+49a` stores the flags, and the function returns them.

**Original-instruction modeled leaves (not reconstructed):** scene query
`001446a0` (static `00145740` + `00267ed0`), sin/cos `00143560/00143620`, RNG
`0011ad58 → 00114010`, sound request `00156ad0` with its EE-side audio library
(voice table at `a82640`, soft-float double routines, DI/EI), and `0015fc10`. Every
executed modeled instruction is compared with the authenticated ELF. The
[instruction packet](../analysis/player_constraint/functions.json) holds 6
routines, 1,456 words, all verified by PS2DInfo `--require-all-bytes`.

**New C helpers** (exported through `hg_ee_fp` ops 8/9): exact `div.s`
round-to-nearest-even and VU0 `vrsqrt` (chop) using integer arithmetic. They are
differentially tested against the shared oracle.

### Explicit contracts and external effects

- **Guest stack layout (host-only `HG_GUEST_FRAME`).** For a triangle hit,
  `00145740` copies a never-written fourth-vertex stack quad into the hit record
  at `3f3a00` (`145b10..145b1c`). In the original, the later floor query in
  `0015fc10` copies the actor pointer that `00267ed0` saved there during
  `0015ebc0`'s queries. Calls from the C `0015ebc0` therefore announce the
  original 0x70-byte frame, and the bus runs modeled callees at that depth. The
  guest stack itself stays excluded from comparison. The `missing-guest-frame`
  control shows the difference is exactly `3f3a00..3f3a0c`.
- **Fifth argument.** The bus has four argument slots. `00156ad0`'s fifth R5900
  argument `t0` is the constant 1 (delay slot `0015fbb8`). The runtime driver
  supplies it explicitly, as M8 documented for the same callee.
- **CP0 Status.** The sound request's DI helper `0010cca0` reads `Status`, which
  is CPU state rather than RAM. The model now fails closed unless a value is
  supplied. Every frame runs with `EIE` both set and clear, and the resulting
  memory is identical in all 7 frames.
- **Instruction model additions** (`tools/ee_subset.py`, required by the RNG and
  audio library): `multu`, `mult1` (LO1/HI1), `mfhi`, `mflo`, `daddiu`, `dsrl`,
  `dsra`, `dsubu`, `sync`/`sync.p`, `mfc0 Status`, `di`, `ei`. Each is
  synthetically tested. Previously these instructions raised an error; no
  existing behaviour changed.
- **Comparison exclusions are unchanged from M8–M10:** guest stack
  `01fe0000..02000000`, and libpad IOP DMA receive buffers only if execution
  neither reads nor writes them (48 asynchronous differing bytes across all
  stages, none touched). No other exclusion is used.

### Composition and state continuity

`hg_player_constraint_camera_fixed` layers the C `0015ebc0` over the unchanged M10
dispatcher/history and M9 camera bus. The M10 composition keeps its modeled
constraint, so earlier regressions are unaffected. Each frame starts from an
independently captured original dispatcher-entry state. The calculated
1,344-byte player and 336-byte camera structures from the previous frame are
carried forward, and all 6 handoffs match the next entry capture exactly. This
verifies the selected connected operation, not autonomous inter-frame execution.
Input polling, other actors, timers and rendering between frames come from the
next entry capture.

## Limits

Hybrid C with original-instruction-modeled leaves. One static feature, one
direction of approach, `+4ad = 0`, foot-tier contact only. Head, middle and rear
pushes, `+4ad` thresholds and bump variants are covered by the
original-instruction differential on perturbed retail scene state, not by retail
observation. Special surfaces (`0015eaf0`) fail closed. FP under PCSX2 v2.8.2
defaults: no flags, exceptional values or timing. This is not general collision,
autonomous inter-frame execution, all-C, byte matching, a native port or
whole-game equivalence.
