## Reconstruction

All new code is in `src/resource_loader.c` and declared in `src/resource_loader.h`.

- **`hg_render_node_list` (`00143150`).** Calls the M8 walker
  `hg_actor_update_type2` between service marks `0xfffffff6 (0x143150, 1/0)`
  and its original `0x20` guest frame. Nothing is duplicated.
- **`hg_camera_anchor_node` (`0019c8a0`, state 1).** Sub-state 0 clears the
  timers, draws two texture words through `0011ad58` (`((r>>16)<<7)>>15`) and
  falls into sub-state 1. Sub-state 1 waits for release: it zeroes the timer
  if `003f976c` is set; otherwise, while `003f976d < 2`, it adds 0.016 and
  advances at ≥ 4.0. Sub-state 2 is active when the four-byte gate sum is 0
  and the player byte `003f92d1` is set. It then adds 0.016 to `+60` and 0.8
  to `+6c` and wraps at > 1.4. It projects the anchor (0, −1.5, 1.2, 1)
  through the view matrix `70000000`, drifts it by 0.03·forward·`+6c` and
  writes the `70000900..94f` sprite block (scale, flags, identity rotation,
  local-to-world row). It then emits two sprites with the node's texture
  words. The common tail handles the `003f9753` companion object (`00196ad0`
  allocate, or `+18 = 2` release). Any other state domain-faults with 0x70.
- **`hg_camera_particle_field` (`002f7830`, state 1, variant 0).**
  - Rotates three layer directions by the node's angles.
  - Scrolls three layers by (previous camera − camera) + speed·direction, wrapped into [−64, 64].
  - Opens a packet with the resource from `00138370`.
  - For 4 groups × 32 particles: wraps the offset position, culls behind the camera (forward·p < 0.16) and outside 34 < |p| < 64, and fades by sin(π(d−34)/30) clamped to [0, 1].
  - Emits a camera-facing billboard (pitch and yaw, weight 1 − |pitch|/1.2566 clamped at 0) and a horizontal quad (weight |pitch|/1.2566) through `0014d4f0`.
  - Closes the packet and stores the camera position for the next frame's delta.
  - Any other state or variant domain-faults with 0x72.
- **`hg_player_model_draw` (`0012bc70`) and its observed callees.**
  - `0012bc70` is skipped while `003f92d1` is zero. Otherwise it clears the
    player `+e0` bits `0x30000000` while any gate byte is set, sets them
    otherwise, then calls `00123ee0(player, 0)`.
  - `model_draw` (`00123ee0`) requires `+e0 & 0xc0000000`. If `+4c` is 0.0
    it returns drawn. It selects `00125d60(1/5/2, ctx+310, owner)` by
    `+50 & 0x0f000000`, then calls `00124010`.
  - `model_draw_type` (`00124010`) handles type 3: `00128de0(f12 = 1.0,
    a0 = type word)`, then `00125f30`, `00126180` and `00128e80`. It requires
    `gp+2a24 == 0`.
  - `model_draw_mesh` (`00125f30`) calls the light setup (`+50 & 00f00000` in
    {00100000, 00200000}) and the shadow quad (`+50 & 30000000 == 30000000`),
    then emits the mesh with `00152aa0` and a 0x30 packet header on stream
    `gp+2a50`.
  - `model_light_setup` (`00129020`, light mode 2.0):
    - builds the `sp+70` parameter block for `00151c40`;
    - sets `70000700` = model matrix `(gp+2a40)+50` × (`+190..198`, 0);
    - sets `70000710.xyz` = v·rsqrt(v·v) (VU0 chop) and `.w` = 0 + v.w;
    - writes the light-matrix column `+8/+18/+28/+38`;
    - computes the attenuation (1 − |v| / (`+1a8` + light`+20`)) ×
      `+19c..1a4` × `+40..48`, the ambient quad, and `+3c` = 2²³ + 128·`+4c`;
    - clears `+1c`.
  - `model_shadow_quad` (`00129e40`) builds the identity matrix scaled 4.2,
    rotates it −π/2 with `00143c60`, takes row 3 from the bone, transforms the
    four `0037bab0` corners into `sp+30`, writes the colour (2, 2, 2, 124) and
    emits `0014a0a0(s, 2, 2, 0)`, `0014d4f0(s, sp+30, 70000700, tag)` and
    `0014a0a0(s, 0, 0, 0)`.

  Each unobserved branch fails closed with a fault code:
  - 0x74: `a1 == 1`;
  - 0x75: another model type, or `gp+2a24 != 0`;
  - 0x76: `00129600`/`00129840` modes, or mesh data with bit 24;
  - 0x77: a light mode other than 2.0, or a type in {40, 20, e, d, 2};
  - 0x78: out of range, bit 21 clear, or point lights (count > 0).
- **Guest-sp contract.** `HG_GUEST_FRAME (bytes, 1)` now returns the guest `sp`
  of the entered frame (`0x1ff0800 − frame depth`). `00129020` and `00129e40`
  pass the original callees `00151c40` and `0014d4f0` pointers to parameter
  blocks at `sp+70` and `sp+30`, above the callee's frame. Existing C ignores
  the value.
- **Host seam `HG_CALL_WIDE_A3` (`0xfffffff4`, low/high).** Supplies the full
  64-bit `a3` for the next modeled `0014d4f0` call. The driver refuses it for
  any other callee and checks that its low word equals the `a3` operand.
- **Interpreter subset.**
  - `div`/`divu` (LO = quotient truncated toward zero, HI = remainder, both
    sign-extended; divide by zero and overflow fail closed), for the
    `0019c8a0`/`002f7830` paths.
  - VU0 `vmaxbc`/`vminibc`/`vmax`/`vmini`: exact operand selection in
    sign-magnitude order; exponent 255, denormal and mixed-sign-zero operands
    fail closed. Needed by the original `0012bc70` leaves (`vminibc.w` at
    `00155814`).

## Integration and ownership

`hg_player_frame_continuous` now calls `0012bc70` (`0012f8f0`) and `00143150`
(`0012f900`) on the carried bus at their original positions, replacing the
M13 external seams. The frame bus routes `0012bc70`, `00143150`, `0019c8a0`

`00126180`, `00128e80`, `00151c40`, `001a6dc0`, `002a20b0` and every leaf)
run original instructions.

The `hg_camera_update` comment that described these regions as render-facing
external was replaced with the M15 ownership statement. No projection value
is stored at camera return. The negative control
`camera-return-projection-store` proves that such a store is rejected.

**External RNG draws.** The unreconstructed `0013ce80` draws from the shared
LCG (`*(0037b208)+0xa8`; `state·0x5851f42d4c957f2d + 1`) between frames. The
verifier measures the step count from the native states: LCG distance minus
the tail's own draws, which the original oracle (`0012bc70` then `00143150`) counts. That is 1 per
frame, 3 at 10178. At the `0013ce80` seam it replays that many original
`0011ad58` executions. Only the count is an external input, like the recorded
pad input; every value is computed by original instructions. The verifier
fails if any external draw would precede `00143150`. The control
`omitted-external-rng-draws` shows that the replay is required.

## Limits

- Observed obs3 corridor only:
  - render nodes: node state 1, particle variant 0, the four observed nodes;
  - player model: type 3, light mode 2.0, no point lights.

  Other states, variants and modes fail closed.
- Packet bytes in the render streams are compared same-input only, because
  their cursor positions depend on the external services that run before them.
- Light-matrix bytes `0xc88–0xd1b` are verified at the `model-draw`
  production checkpoint. At native stops they are excluded while the value
  from the later unreconstructed writer is live. Before M15 they matched only
  because no code wrote them.
- GS timing, DMA submission and the unreconstructed tail services stay
  external.
- No byte matching, full-game equivalence, static recompilation or native
  port is claimed.
