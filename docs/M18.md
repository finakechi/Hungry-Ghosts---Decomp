# M18 — original-driven front end and game-state lifecycle

## Resume here

**Status: bounded partial result.** The M17 synthetic stand-ins for the
front end are replaced by C reconstructed from the original code: fades,
the controller service, the title menu, the memory-card check, the new-game
state and the pause menu. This C, connected to the M17 lifecycle C, runs
**16,273 consecutive native frames** (seq 2439 → 18712) of one recorded
PCSX2 session of the original game, with **0 failing frames**. That covers
all three required scenarios:

1. Title → New game → area load → active gameplay.
2. Gameplay → Pause → Resume → gameplay.
3. Gameplay → Pause → Quit → teardown → Title → New game → area load →
   gameplay.

Each frame carries the C state forward and compares it with the next native
stop. All 10 compiled C defects are rejected, and a null control passes.

The result is a bounded partial because three criteria are not fully met:

- **Authentic Continue is not exercised.** No memory card holds a save, and
  creating one is a new persistent write outside the milestone
  authorization (see [Continue](#continue-deliverable-d)).
- **The loader thread is not C in this run.** The C issues every load
  request (checked against the native task record), but the EE loader
  thread 00130220 and the IOP reads stay external (E3).
- **Scene, actor and dialog code is external.** It requests some fades and
  the new-game dialog decision. These inputs are declared, recovered from
  the native record and reported (E5, E10, E12, E13). They are not C.

**Next action.** Owner review of this branch. Then either:

- authorize one owner-made memory-card save in a copy of the profile, which
  would let the same runner verify authentic Continue; or
- reconstruct the loader thread 00130220 so that E3 becomes C.

## Original-byte findings

- **Fade block** `gp+2f40` (`003eaeb0`):
  - Byte fields: `+0` phase (0 clear, 1 fading in, 2 black, 3 fading
    out), `+1` layer, `+2` blend, `+3` kind (0..7, jump table `003db1f0`).
  - `+4` s16 level 0..0xff; `+6` s16 step.
  - `+8` music-fade state; `+c` f32 music target (`level × 64 / 128`);
    `+10`.
  - `700000d4` is the pause-capture flag. Fade-out mode 1 (kind 4) sets it
    to 1, the frame start `00148970` captures the frame and sets it to 2,
    and the end of the kind-4 fade clears it.
- **Pad block** `0095e340`:
  - The first 0x100 bytes are the libpad DMA buffer, pointed to by
    `[003f0a50]`.
  - Then `+100` port, `+104` slot, `+108` id (7 = DualShock 2), `+10a` port
    state (11 states, table `003db210`), `+10b` pressure mode.
  - `+1c0..+1fc` pressure floats, `+200..+220` analog floats.
  - `+224` held, `+226` previous, `+228` edge, `+22a` repeat, with
    timers; `+230..` hold a second button set.
  - The game copies these to `gp+2f90..2fc8`.
  - libpad (`0010d000..`) is the IOP boundary.
- **Title.**
  - Lifecycle mode 00121be0 major 0 loads the title resources: `0x50`,
    then system kind 7/8, then PACK `0012dbd0`. Minor 3 calls the card
    scan `002cf020`.
  - The scan reports 1 (save present) or 2 (no card/save), with state at
    `00966500..0096651c`; `70000410` is the save-present flag.
  - Major 1 runs the overlay title `00a87880`, with minor = mode `+9`.
    Minor 0 sets up the scene (`00a88660`); minor 1 is the presentation
    until the scene clears `+1a`; minor 2 is the menu (`+11` choice, `+1c`
    attract timer `0x4b0`); minors 3/4 are the confirm and timeout fades.
  - Without a save, the menu cursor skips row 1 (続きから, Continue).
  - Choice 0 (New game) goes to major 2, which installs the gameplay mode
    0012d1c0.
- **New game.** `00141980` sets the area triple (1,0,0) at `003fa1b0`, the
  empty name (`0011af00` with format `003db280`), default options
  (`00141810`) and controls (`001418b0`).
- **Pause.**
  - `00162750` takes its state from mode `+c` (table `003db630`, 18
    entries).
  - The cursor is `+20` (0 Resume … 3 Quit).
  - Resume fades out with next state `0x11` and then returns to sub 1.
    Quit is state 2 with next state 4, then the confirmation (4 → 7).
  - The gameplay mode then runs teardown 0012f800, which reinstalls
    00121be0 with `700000f8 = 1`.

## Connected native run

`tools/run_front_end_native.py` starts from **one** native full capture
(`title-menu-input-ready`, seq 2439) and runs `hg_main_unit` frame by frame:

1. M17 dispatch to the M17/M18 C modes.
2. The main-loop tail: the C fade service, then the vblank wait with the C
   handlers.
3. The main-loop head: the C controller service.

After every unit, the C-owned state is compared with the next native stop
record. C state is carried forward and never restored from native.

**Compared every unit (434 bytes), plus every load request:**

- mode block `003ead30..58`;
- fade block `gp+2f40..47`;
- counters `gp+2f7c..87`;
- pad copies `gp+2f90..cb`;
- pad port and buttons `0095e440..537` and `0095e564..57f`;
- vblank counter and flag;
- scratch `700000c4`, `cc`, `d4`, `f8..ff`;
- save flag `70000410`;
- area triple `003fa1b0..b3` and `003fa1c4`;
- for every load request, the task-record kind (`+32`) and resource id
  (`+44`). A native busy rise with no C request is also a failure.

**Declared external inputs** (not C; each is injected or modelled, listed
in the receipt, and confined to the stated context):

| | Input | Treatment |
|---|---|---|
| E1 | libpad / IOP | DMA buffer of stop N+1; `scePadGetState` → 6; `scePadRead` 0010db90 runs as **original instructions** (114 words) |
| E2 | vblank timing | native `0095e300` delta = number of C handler pairs |
| E3 | loader thread 00130220 + IOP reads | loader cells of stop N; requests run the C `00130150/00130170` and are checked |
| E4 | CreateThread | returns the native `task+34` |
| E5 | new-game dialog/name/contract UI `002cf330` | returns 1 on the frame the native left major 1 |
| E7 | memory card (none inserted) | sceMc sync → −1, get-info → 0 |
| E8 | analog conversion `0013e5b0` | its outputs from stop N+1 |
| E9 | all other callees | no memory effect, return 0, counted; other record bytes from stop N+1 |
| E10 | fades requested by scene/actor code | only in three declared contexts, only when the C made no setter call: the setter call is recovered from a fresh native fade start and run through the **C setter** (8 recoveries) |
| E11 | frame start `00148970` | pause-capture handshake `700000d4` 1 → 2 only |
| E12 | title minor 1 | mode `+1a` (presentation end) from stop N+1, written by the scene `00141470` |
| E13 | title scene setup `00a88660` | its fade-in recovered from stop N+1 and run through the C `001390b0` (1 recovery) |

The music-fade words `gp+2f48..53` are advanced by the external sound
service `00156740` and are not compared at runtime. The C music-fade
setters are checked by the original-instruction differential only.

fails (as the Quit and title-return fade controls show).

## Original-instruction differential

`tools/verify_front_end_differential.py` (model differential). The original
words run in the `ee_subset` interpreter, against the C, on identical
memory. It compares ordered writes and calls (with contract registers t0–t3
and f12–f14) and return values.

```sh
python3 -B tools/verify_front_end_differential.py --elf "$HG_ELF" --overlay local/m18/ovl/A0_B09.BIN \
    --cases 1500 --capture local/m18/native/full/title-menu-input-ready \
    --capture local/m18/native/full/s1-active-settled --capture local/m18/native/full/s2-pause-menu \
    --capture local/m18/native/full/s3-title-menu-ready --output <fresh>.json
```

- 27 entries, 7,500 cases each, on 5 bases (ELF image plus 4 native full
  captures): **202,500 cases, 0 mismatches**.
- Executed words per entry are in results.json. Unexecuted words are
  fail-closed paths and the unreconstructed pause states (`00162750`
  405/767).
- Synthetic CI (`tests/test_front_end_differential.py`) reruns the
  differential on an image built only from the published packet. It also
  rejects 4 compiled defects and checks that the native-control anchors
  are unique.

## Limitations

- The loader thread, IOP, GS draws, sound, scene/actors, the new-game
  dialog and the gameplay coordinator are external (E1–E13). The run
  verifies the front-end and lifecycle state, not the world simulation.
- The music-fade words and the bytes outside the recorded regions are not
  compared at runtime.
- E10 can mask an omitted C fade-setter call inside its three declared
  contexts (see the controls above).
- Pause states 3, 5 and 8–0x10 (submenus not taken in the session) fail
  closed. Authentic Continue is not exercised.
- One session and one controller, recorded with no memory card.
