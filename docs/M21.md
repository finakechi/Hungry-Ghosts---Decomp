at `00a87800`. Apply that base for overlay file offsets. The receipt records
the individual range hashes. Original comparison is scoped to the Japanese EE.
IOP playback and DMA plumbing beyond the host CDVD boundary remain external.

## Reproduction

Run from the M21 worktree with a fresh ignored output directory. The private
fresh title stop directory contains `live-create.json`, `live-dialogue-init.json`,
`live-voice.json`, `live-glyph.json`, `live-reset.json`, and
`live-presentation-done.json`, with matching debugger PNGs and
`live-identity.json`. The paired AREA1 captures are in `native/full`.
Use the breakpoint PCs above in the official debugger. Capture the indicated
guest regions via PINE while paused. At init, glyph and reset include the
`00a6b0f0` task slot. At the glyph call, `s0 = 00a6bcf8` determines the
token address before the draw call's delay slot. The comparison binds the
native images and checkpoint data without consuming them as frame inputs.

```bash
iso='../Hungry Ghosts (Japan).iso'
elf=local/extracted/japan/SCPS_150.46
fresh=local/m21
out=local/m21/reproduce
mkdir -p "$out"

python3 -B tools/hg_identify.py "$iso" --build japan --output "$out/identity.json"
python3 -B tools/verify_title_scene.py --iso "$iso" --library "$out/title.so" \
  --output "$out/title.json" --live "$fresh" --skip 100 --advance-interval 32 --negative-controls
python3 -B tools/verify_title_scene.py --iso "$iso" --library "$out/title-neutral.so" \
  --output "$out/title-neutral.json" --live "$fresh" --until-reset
python3 -B tools/verify_scene_area_entry.py --iso "$iso" --native "$fresh/native" \
  --library "$out/area.so" --output "$out/area.json"
python3 -B tools/verify_title_hgscript.py --iso "$iso" --native ../decomp-m18/local/m18/native \
  --library "$out/m19-m20.so" --output "$out/m19-m20.json"
python3 -B tools/verify_resource_job.py --elf "$elf" --ps2dinfo local/references/PS2DInfo \
  --negative-controls --output "$out/m19-job.json"
python3 -B tools/verify_resource_retail.py --iso "$iso" --m4 local/m4/runtime \
  --m7 local/m7/captures --output "$out/m19-retail.json"
python3 -B tools/run_front_end_native.py --native ../decomp-m18/local/m18/native \
  --start title-menu-input-ready --library "$out/m18-native.so" --output "$out/m18-native.json"
python3 -B tools/run_resource_lifecycle.py --iso "$iso" --native ../decomp-m18/local/m18/native \
  --library "$out/m19-lifecycle.so" --output "$out/m19-lifecycle.json"
python3 -B tools/hgscript_differential.py --elf "$elf" --iso "$iso" \
  --scratch "$out" --output "$out/m20-differential.json"
python3 -B tools/verify_player_continuous.py --elf "$elf" --ps2dinfo local/references/PS2DInfo \
  --capture-dir local/m13/captures --area-image "$iso" --lifecycle --output "$out/m17-corridor.json"

HG_JAPAN_ISO="$PWD/$iso" python3 -B -m unittest discover -s tests -v
python3 -B tools/hg_verify.py run --profile full
git diff --check
```

The strict builds and title scene ASan+UBSan test used these commands.

```bash
for compiler in gcc clang; do
  "$compiler" -std=c11 -O2 -Wall -Wextra -Werror -pedantic -ffp-contract=off \
    -fPIC -shared -Wl,--no-undefined src/scene/title_scene.c src/hgscript/{hgscript,timed,title}.c \
    src/{resource_loader,disc_read,front_end,game_lifecycle}.c -o "$out/runtime-$compiler.so"
  "$compiler" -std=c11 -g -O1 -Wall -Wextra -Werror -pedantic -ffp-contract=off \
    -fno-omit-frame-pointer -fsanitize=address,undefined -fno-sanitize-recover=all -I src \
    tests/title_scene.c src/scene/title_scene.c src/hgscript/{hgscript,timed,title}.c \
    src/{resource_loader,disc_read}.c -o "$out/title-$compiler-san"
  ASAN_OPTIONS=detect_leaks=1:halt_on_error=1 UBSAN_OPTIONS=halt_on_error=1 \
    "$out/title-$compiler-san"
done
```

The standalone suite passed 462/462 with the retail checks enabled.
GCC and Clang passed the strict builds and the title scenario sanitizers.
The M19 job comparison accepted 36 jobs and 765 sleep/return comparisons,
with four measured negative controls. The M19/M18 connected test matched
all 11 request/completion sequences and all three full checkpoints. The M20
standalone differential and earlier cold title integration check passed.

## Remaining boundary

The verified title window and AREA1 worker interval have separate C entry
conditions. The fresh PCSX2 session traverses the name/contract/save UI between
them. A gameplay-to-gameplay transition still needs an observed destination
and runtime verification. The current evidence supports title scheduling,
dialogue ownership, AREA1 loader handoff and the pre-existing controlled
corridor, with external renderer and IOP services. No game or emulator assets
are distributed. No save was written or final reconstruction objective chosen.
