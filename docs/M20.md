# M20 — HGScript runtime and timed dialogue

M20 reconstructed the resident EE consumers for paged text and timed dialogue on
the Japanese SCPS-15046 build. Three authenticated timed records ran from
initialization through termination using independently carried guest memory.
The original-instruction interpreter and C agreed on guest writes and the
arguments of each draw and audio request. Two authenticated static records also
passed metadata, page selection, measurement, and positioned draw comparisons.

## Resumed state

The existing MainPC worktree was `decomp-m20`, branch
`research/m20-hgscript-runtime`, at
`86a5670852d47c4ead140e5c8e40a5289f773053`. The index and tracked working files
were clean. The untracked work included the C text walker and its header, an
instruction harness, an emulator probe, Ghidra search scripts and backup revisions.
Ignored `local/` held the extracted Japanese ELF, the 74-script corpus, disassembly,
emulator screenshots and several failed differential logs. The latest log
reported write mismatches and missing scripted renderer returns. It supplied
no passing runtime receipt. No test, debugger or emulator process was running
at recovery. The DeepSeek store could not be read as an ordinary SQLite database,
so recovery used the surviving files and logs.

M20 retained those artifacts and reused the recovered text consumer addresses,
the formatter and width research, the guest bus and the repository's EE interpreter.
The recovered harness file was revised to execute original nested instructions
directly and give original and C independent guest memories. The pre-edit C,
harness and probe are also preserved in ignored `local/m20-resume/interrupted/`.
Exploratory scripts and older revisions are outside the milestone commits.

The static consumer resolves an index against the table at `003f4300`, reads the

from collection word 1. A word encodes a six-bit command and a 26-bit unsigned
operand. Static entry points count or seek pages (`00182a60`, `00182ae0`),
measure a page (`00182b50`, `00183070`), draw by address or handle
(`001830b0`, `001836b0`), count line advances (`00183840`, `00183910`) and
resolve leading metadata (`001839f0`, `00183a30`).

The timed caller at `00214c68` selects a collection from the resource table
through `00138370`, calls `001ccd80` with a record index, then clears instance
word 0 to start playback. The frame caller `0025c170` runs `001ccfa0` then
`001cd9c0`. The dispatcher at `001cd048` reads the current word, masks
`0x3f`, shifts the operand by six and indexes `003dc5b0` for commands 0–10.
The phase-1 wait uses a second table at `003dc580`. The separate
`0025cf60` prelude checks a leading command 11 and forwards two packed
arguments to `0011f880`. Its game-system effect remains external.

## Connected verification

The instruction runner uses the original resident ELF and re-authenticates the
entire Japan ISO. Each side reads the same PACK member bytes into an independent
guest bus. The fixture supplies activation, the input edges and asynchronous
voice status. It independently returns 24 from each renderer request.
The other external seams record audio and prelude requests. The interpreter
executes the original initialization, dispatch, display fade, measurement,
positioning and formatting code. It executes the original memcpy and uses
semantic hooks for the three MMI-optimized string library leaves. Comparison
checks the union of guest byte writes outside CPU stack frames after each call
and checks request order, defined arguments, style fields and pointed-to text
digests. The fixture supplies no captured runtime writes or renderer results.

## Content and loader interface

The content tool retains the original lossless representation. It now reports
the EE command and operand and resolves text, cue and leading metadata offsets
against member bytes independently of the legacy sequential guess. The
[corpus receipt](../evidence/m20/corpus.json) records 2,541 members and 74/74
byte-exact rebuilds. The direct rules resolve all 10,633 text references,
1,326 timed cue references and 2,664 leading metadata references in the corpus.
The index exposes opcode counts and reference counts without dialogue contents. Legacy count-matched and unresolved categories
stay visible for readers of earlier results.

For M19, provide the aligned guest address of the loaded, authenticated
collection and keep it mapped while the instance runs. The branch's
[`HGScriptEnv`](../src/hgscript/hgscript.h) accepts the existing guest bus and
synchronous external call adapters. Allocate `HG_SCRIPT_TIMED_SIZE` bytes of
guest state, initialize with the collection address and record index, and
activate by clearing the first state word as the original caller does.
Call timed tick, then timed draw once per frame. The caller services audio,
pad input and shared game status. The static entry points use the published
handle table or an explicit record and pool. No resource loader code is required
for this interface.

## Reproduction and remaining scope

Run from the M20 worktree with owner-local `HG_ELF` and `HG_JAPAN_ISO`.
Output and scratch directories must be private. The historical profile additionally
needs the owner PCSX2 AppImage, pinned PS2DInfo and the captured M4–M12 inputs.
The commands used fresh output names under `local/m20-resume/`.

```sh
python3 -B tools/hgscript_differential.py --elf "$HG_ELF" --iso "$HG_JAPAN_ISO" \
  --scratch local/m20-resume --output local/m20-resume/differential-qualified.json
python3 -B tools/hg_content/cli.py corpus "$HG_JAPAN_ISO" \
  --expect-sha256 8ca1513c8417c0a40b838ff5edf22a2360f43bce1b0458693a95a6efdafd994e \
  --output local/m20-resume/corpus-final.json
python3 -B -m unittest discover -s tests -p 'test_hg_content_*.py'
python3 -B -m unittest discover -s tests -p 'test_hgscript_runtime.py' -v
cc -std=c11 -g -O1 -Wall -Wextra -Werror -pedantic -ffp-contract=off \
  -fno-omit-frame-pointer -fsanitize=address,undefined -I src/hgscript \
  tests/hgscript_runtime.c src/hgscript/hgscript.c src/hgscript/timed.c \
  -o local/m20-resume/hgscript-sanitizers
ASAN_OPTIONS=detect_leaks=1:halt_on_error=1 UBSAN_OPTIONS=halt_on_error=1 \
  local/m20-resume/hgscript-sanitizers
clang -std=c11 -Wall -Wextra -Werror -pedantic -ffp-contract=off -fPIC -shared \
  -Wl,--no-undefined src/hgscript/hgscript.c src/hgscript/timed.c \
  -o local/m20-resume/clang-hgscript.so
python3 -B -m unittest discover -s tests -v
python3 -B tools/hg_verify.py run --profile full --config local/m20-resume/historical-config.json
git diff --check
```
